# Функционал плагина EventSheet

## Описание
EventSheet Plugin - это визуальный редактор событий для Godot 4, позволяющий создавать игровую логику без программирования, используя систему условий и действий.

## Основные возможности

### 🎯 Визуальное программирование
- Создание игровой логики через графический интерфейс
- Система "условие → действие" без написания кода
- Поддержка вложенных событий и подсобытий

### 📋 Система событий
- **Условия** - проверка критериев (например, "Нажата ли клавиша пробел?")
- **Действия** - выполнение операций при выполнении условий
- **Подсобытия** - дополнительная логика внутри основных событий

## Детальный функционал

### 📝 Редактор событий
- **Визуальный интерфейс** - создание логики через drag & drop
- **Блоки событий** - группировка условий и действий
- **Подсобытия** - вложенная логика с отступами
- **Комментарии** - документирование кода
- **Группы** - организация блоков по категориям

### ⚡ Система выполнения
- **EventSheetRuntime** - движок выполнения событий
- **Кэширование скриптов** - оптимизация производительности
- **Обработка ошибок** - система отладки и логирования
- **Контекстное выполнение** - привязка к узлам сцены

### 🎯 Условия (Events)
#### Системные условия:
- `System.every_tick` - выполнение каждый кадр
- `System.ready` - выполнение при готовности узла
- `System.process` - выполнение в _process
- `System.compare_two_values` - сравнение значений
- `System.is_between_values` - проверка диапазона
- `System.evaluate_expression` - вычисление выражений
- `System.test_regex` - проверка регулярных выражений
- `System.is_value_type` - проверка типа данных
- `System.is_number_nan` - проверка на NaN
- `System.is_group_active` - состояние группы
- `System.object_uid_exists` - существование объекта

#### Условия ввода:
- `Input.is_action_pressed` - проверка нажатия клавиш
- `System.input` - обработка пользовательского ввода

#### Условия объектов:
- `Object.compare_position` - сравнение позиций
- `Object.compare_two_variables` - сравнение переменных объекта

#### Условия переменных:
- `Variables.compare_variable` - сравнение переменных
- `Variables.is_boolean_set` - проверка булевых значений

#### Угловые условия:
- `System.angle_is_between_angles` - угол между углами
- `System.angle_is_clockwise_from` - направление по часовой
- `System.angle_is_within_angle` - угол в пределах

### 🚀 Действия (Actions)
#### Системные действия:
- `System.print` - вывод в консоль

#### Действия с объектами:
- `Node2D.set_position` - установка позиции

#### Действия с переменными:
- `Variables.set_variable` - установка значения переменной
- `Variables.add_to_variable` - добавление к переменной

### 🔧 Управление переменными
- **VariableManager** - централизованное управление
- **Глобальные переменные** - доступны во всем проекте
- **Локальные переменные** - ограниченная область видимости
- **Типизация** - поддержка различных типов данных
- **Автоматическое преобразование** - конвертация строк в числа/булевы

### 🛠️ Инструменты разработчика
- **EventSheetDebugger** - отладка выполнения событий
- **EventSheetErrorHandler** - обработка ошибок
- **Drag & Drop система** - перетаскивание элементов
- **Undo/Redo** - отмена и повтор действий
- **Копирование/Вставка** - работа с буфером обмена
- **Автосохранение** - сохранение в JSON формате

### 🎨 Интерфейс
- **Панель событий** - левая часть экрана
- **Панель действий** - правая часть экрана
- **Разделитель** - настраиваемое разделение областей
- **Иконки** - визуальное представление элементов
- **Цветовое кодирование** - различение типов блоков
- **Анимации** - плавные переходы (настраиваемые)

### 📁 Структура файлов
- **JSON формат** - сохранение событий в читаемом виде
- **Модульная система** - расширяемые условия и действия
- **Кэш иконок** - оптимизация загрузки ресурсов
- **Автозагрузки** - системные синглтоны

### 🔌 Интеграция с Godot
- **Главный экран** - отдельная вкладка в редакторе
- **Привязка к узлам** - работа с объектами сцены
- **Автозагрузки** - системные менеджеры
- **Настройки редактора** - сохранение пользовательских настроек
- **Предпросмотр ресурсов** - генерация иконок объектов
